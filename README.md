# 🛡️ الأمن السيبراني — عرض تفاعلي مباشر

عرض للمعلمة على السبورة، وكل مجموعة معها آيباد. الآيباد يعرض سؤال الشريحة الحالية، وإجابات المجموعات تظهر للمعلمة مباشرة في لوحة جانبية.

| الصفحة | لمن؟ |
|---|---|
| `index.html` | صفحة البداية (فيها زر المعلمة وزر المجموعات) |
| `teacher.html` | المعلمة: العرض + لوحة الإجابات |
| `student.html` | الآيباد: لكل مجموعة جهاز |

> بدون إنترنت؟ `teacher.html` يشتغل كعرض عادي، ولوحة الإجابات تتعطّل بس.

---

## ١) إعداد Firebase (مرة وحدة فقط)

1. ادخلي [console.firebase.google.com](https://console.firebase.google.com) وأنشئي مشروعًا جديدًا (مجاني).
2. **Build ← Realtime Database ← Create database**، واختاري أقرب موقع، ثم **Start in locked mode**.
3. افتحي تبويب **Rules**، وانسخي فيه محتوى ملف `database.rules.json`، ثم اضغطي **Publish**.
4. **Build ← Authentication ← Get started ← Sign-in method**، وفعّلي **Anonymous**.
5. **⚙️ Project settings ← Your apps**، واضغطي أيقونة الويب `</>`، وسمّي التطبيق بأي اسم.
6. انسخي القيم اللي تظهر لك إلى ملف `firebase-config.js`، وتأكدي إن `databaseURL` موجود فيها.

7. أضيفي المعلمات (القسم التالي).

> ملاحظة: نشر قيم `firebase-config.js` على GitHub آمن، لأن الحماية تجي من قواعد قاعدة البيانات (الخطوة 3)، مو من إخفاء المفتاح.

## ٢) إضافة المعلمات 👩‍🏫

كل معلمة لها:
- **رمز**: أرقام أو حروف إنجليزية صغيرة، مثل `101`. هذا الرمز نفسه هو **رمز الفصل** اللي تكتبه الطالبات في الآيباد، فالأفضل يكون رقم قصير.
- **رقم سري**: 4 أرقام، تكتبه المعلمة عند الدخول.

**الإضافة من Firebase Console ← Realtime Database ← تبويب Data:**
1. مرّري الماوس على اسم قاعدة البيانات في الأعلى واضغطي **＋**.
2. في **Key** اكتبي `teachers` واضغطي **＋** اللي جنبها لإضافة فرع.
3. في Key اكتبي رمز المعلمة (مثل `101`)، واضغطي **＋** عشان تضيفين تحته حقلين:
   - `name` = اسم المعلمة، مثل `أ. نجود`
   - `pin` = الرقم السري، مثل `4821`
4. اضغطي **Add**. وكرري الخطوات لكل معلمة: `102`، `103`، ...

الشكل النهائي:
```
teachers
 ├─ 101
 │   ├─ name: "أ. نجود"
 │   └─ pin:  "4821"
 └─ 102
     ├─ name: "أ. سارة"
     └─ pin:  "7350"
```
- **لتغيير الرقم السري:** عدّلي قيمة `pin`.
- **لإيقاف معلمة:** احذفي فرعها.
- الرقم السري ما يقدر أحد يقرأه من الموقع، والتحقق منه يصير داخل قواعد Firebase.

> ⚠️ لا تكتبين الأرقام السرية في أي ملف يُرفع على GitHub.

## ٣) الرفع على GitHub Pages

1. أنشئي مستودعًا (Repository) جديدًا على GitHub، وارفعي **كل الملفات** اللي في هذا المجلد.
2. **Settings ← Pages ← Source: Deploy from a branch ← main / (root) ← Save**.
3. بعد دقيقة أو دقيقتين يصير الرابط جاهزًا، بهذا الشكل:
   `https://اسم-الحساب.github.io/اسم-المستودع/`

## ٤) في الحصة

- **المعلمة**: افتحي الرابط على جهاز العرض، واضغطي «المعلمة»، وادخلي برمزكِ ورقمكِ السري. بعدها يظهر **رمز الفصل** كبير على شريحة البداية.
  - الجهاز يتذكر رمز المعلمة، أما الرقم السري فيُطلب في كل مرة. وهذا مناسب لو أكثر من معلمة تستخدم نفس الجهاز.
  - **للخروج:** 🏆 ← 🚪 تسجيل خروج المعلمة.
  - **بدون أجهزة الطالبات:** «عرض الدرس فقط».
- **كل آيباد**: افتحوا نفس الرابط، واضغطوا «المجموعات»، واكتبوا رمز الفصل، ثم اختاروا المجموعة. الجهاز يحفظ الفصل والمجموعة.
  - رابط مباشر يتخطى كتابة الرمز: `.../student.html?room=101`
  - نصيحة: من Safari اختاروا «إضافة إلى الشاشة الرئيسية»، عشان تفتح الصفحة بضغطة وحدة.
- لما تنتقلين لشريحة فيها سؤال، يظهر السؤال على الآيبادات تلقائيًا. والشرائح اللي ما فيها سؤال تظهر فيها على الآيباد رسالة «تابعي الشاشة».

### أزرار لوحة الإجابات 📡
| الزر | الوظيفة |
|---|---|
| 📡 (في الشريط السفلي) أو حرف **ج** | إظهار اللوحة أو إخفاؤها |
| 👁 / 🙈 | إخفاء الإجابات عن الفصل لين تكشفينها، عشان ما تنقل مجموعة من ثانية |
| ⏱ 30 ث / ⏱ 60 ث | مؤقت يظهر على كل الآيبادات، ولما يخلص الوقت تنقفل الإجابة |
| 🔓 كشف الإجابة على الأجهزة | يقفل الإجابة، ويوضح لكل مجموعة الصح والخطأ |
| 🏅 نقاط للإجابات الصحيحة | يعطي النقاط لكل مجموعة إجابتها كاملة صحيحة، و⚡ نقطة زيادة لأسرع مجموعة (🥇🥈🥉 جنب الأسماء) |
| ‎+1 بجانب المجموعة | تعطين نقطة يدويًا، وهذا مفيد للإجابات المكتوبة |
| 🧹 مسح إجابات الشريحة | يمسح إجابات الشريحة الحالية فقط |
| 🏆 ← 🆕 حصة جديدة | يمسح كل الإجابات ويصفّر النقاط، وهذا قبل كل حصة |

النقطة الخضراء بجانب اسم المجموعة معناها إن الآيباد متصل.
الأسئلة الذهبية ⭐ عليها نقاط مضاعفة، ونقاط المجموعة وترتيبها يظهرون على الآيباد.

### أكثر من معلمة
كل معلمة لها غرفة مستقلة باسم رمزها، فتقدر أكثر من معلمة تشرح بنفس الوقت بدون ما تختلط الإجابات. ولا تقدر معلمة تتحكم في عرض ثانية بدون رقمها السري.

**لو المعلمة عندها أكثر من فصل:** تضغط «🆕 حصة جديدة» في بداية كل حصة. ولو تبي فصلين في نفس الوقت، تضيفين لها رمزين (مثل `101` و `1012`).

## ٥) تعديل الدرس
كل المحتوى موجود في ملف `lesson.js`، والأسئلة على الآيباد تتكوّن تلقائيًا من الشرائح.
- لإيقاف السؤال على الأجهزة في شريحة معيّنة، أضيفي داخلها: `student:false`
- لكتابة سؤال مخصّص: `student:{ kind:'text', q:'نص السؤال' }`
